# 秒杀系统接口自动化测试实战

> 一个电商秒杀与财务一体化系统的接口自动化测试实践。覆盖认证、商品、秒杀、订单、财务、采购、销售、库存、安全 8 大模块。

## 背景

被测系统：电商秒杀与财务一体化系统（Flask + MySQL + Redis + JWT）
- 核心业务：秒杀（Redis 防超卖）、采购入库、销售出库、财务自动记账
- 技术栈：Python 3 + Flask 3.0 + pytest

## 核心实现

### 1. 公共夹具（conftest.py）

```python
@pytest.fixture(scope="session")
def client(app):
    """测试客户端"""
    return app.test_client()

@pytest.fixture(scope="session")
def auth_api(client):
    """注册/登录/取token的辅助类"""
    class AuthAPI:
        def headers(self, username):
            """注册并返回带 token 的请求头"""
            client.post('/api/auth/register', json={
                'username': username,
                'password': 'test123456',
                'email': f'{username}@test.com'
            })
            resp = client.post('/api/auth/login', json={
                'username': username,
                'password': 'test123456'
            })
            token = resp.get_json()['token']
            return {'Authorization': f'Bearer {token}'}
    return AuthAPI()
```

## 关键实践要点

### 1. 测试数据隔离
- 所有测试账号用 `test_` 前缀，避免污染正式数据
- 每个测试独立注册账号，不共享状态
